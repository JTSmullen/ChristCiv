# Evidence-Based Study Method

## Goal

The exam requires the student to receive one of six questions and produce a coherent 5–8 page handwritten essay in approximately 75 minutes.

The student therefore needs to practice:

1. recognizing the question
2. recalling the thesis
3. reconstructing the argument
4. remembering definitions and contrasts
5. expanding the outline into prose
6. doing all of this under time pressure

The study app should train those exact abilities.

# Retrieval Practice

Retrieval practice means attempting to recall material from memory rather than simply rereading it.

This should be the central study method.

The user should normally encounter:

1. a question
2. a blank response field
3. an attempt
4. the correct outline
5. feedback
6. later repetition

Do not show the study outline before the recall attempt.

Free recall is preferable to multiple choice because the real exam requires generation, not recognition.

# Feedback

Retrieval should be followed by corrective feedback.

The ideal flow is:

`Attempt → Reveal → Compare → Identify misses → Retry later`

Missed information should be made explicit.

The student should know exactly which major points were forgotten.

# Spacing

Do not repeatedly expose the student to the same information in a single block.

Schedule reviews over time.

Failed information should return quickly.

Successfully retrieved information should return later.

Longer successful streaks should produce longer review intervals.

Passive rereading should not count as mastery.

# Interleaving

Mix the six essay prompts.

The actual exam randomly selects a question, so the student should become comfortable switching between topics without warm-up.

Avoid:

- Essay 1 ten times in a row
- Essay 2 ten times in a row

Prefer something like:

- Essay 3
- Essay 1
- Essay 5
- Essay 3 focused card
- Essay 6 contrast

when those items are due.

# Confidence Calibration

Familiarity can create the illusion of knowing material.

Before showing the answer, ask:

> How confident were you?

Use a 1–5 scale.

Compare confidence to actual performance.

A high-confidence failure should receive extra attention.

# Train the Actual Exam

The final performance is not clicking flashcards.

The final performance is a handwritten essay.

Therefore include timed practice.

A recommended simulation:

- 10 minutes — outline
- 60 minutes — write
- 5 minutes — review

Provide Handwrite Mode so the student can write on paper.

# Recommended Study Loop

A strong short session:

1. Skeleton Sprint
2. Full Outline Recall
3. 3–6 focused recall questions
4. One contrast drill
5. Retry one missed concept

Every few sessions, perform a full exam simulation.

# What Mastery Means

Mastery is not:

- having read the notes
- recognizing the right answer
- spending a long time in the app

Mastery is:

- reproducing the thesis unaided
- remembering the argument order
- recalling definitions
- distinguishing similar concepts
- recovering previously missed ideas after a delay
- successfully constructing the essay under exam conditions
